Download YouTube transcripts in bulk, with timestamps, as clean JSON

Pull the full transcript and timestamped caption segments of any public YouTube video or a channel's latest uploads — manual or auto-generated, in your preferred language — ready for search, summaries and RAG.

Updated 2026-10-03Catalog prices and dated sample snapshots from Apify

Transcripts are the most useful part of a YouTube video for anything that isn't watching it: summarising a talk, searching a course library, quoting a podcast, or feeding an AI model that answers questions about a channel. YouTube shows them one video at a time behind a menu, and the official Data API doesn't hand caption text to third-party apps without the channel owner's authorisation. This guide shows how to get the full transcript of many videos at once — plain text plus timestamped segments — for $4 per 1,000 videos.

What you get

One row per video: the video and channel identifiers, the title, the duration, which caption track was used, every language the video offers, the complete transcript as one text string and — unless you turn it off — a segments array of {start, dur, text} objects. A real row from a recorded run, trimmed:

Field Meaning
videoId, url, title The video
channelName, channelId Who uploaded it
durationSeconds Length of the video
language, languageName, isAutoGenerated Which caption track was extracted, and whether YouTube generated it automatically
availableLanguages Every caption language the video offers
text The whole transcript as one plain-text string
segments, segmentCount Timestamped pieces with start time and duration in seconds
error Why a video had no transcript (for example no captions)

Which caption track you get

You set a preferred language (two-letter code, en by default). If the video has captions in that language, you get them. If not, the tool falls back in this order: the first manually created track in any language, then the first auto-generated track (when includeAutoGenerated is on, which is the default), then any track at all. The row always tells you what you received through language and isAutoGenerated, so a pipeline can filter out auto-captions or non-English rows if it needs to.

Step-by-step

  1. Open the tool and paste videos into Video URLs — full watch?v= links, Shorts links, youtu.be links or bare 11-character IDs all work, one per line.
  2. Or set Channel URL (for example https://www.youtube.com/@channelname) and Max videos to take the channel's latest uploads instead. A channel URL overrides the video list.
  3. Pick your Language, and decide whether to Include auto-generated captions and Include segments. Turn segments off if you only need the text — the dataset gets much smaller.
  4. Leave Proxy mode on auto: requests go out directly and switch to a residential proxy only if YouTube starts rate-limiting.
  5. Click Start and export as JSON, CSV or Excel, or read the rows through the API.

Recipes

Turn a channel into a searchable knowledge base

Run the tool with a Channel URL and a generous Max videos, then pass the run's dataset to RAG Text Chunker with inputDatasetId set to the transcript run's dataset ID and textField set to text. You get token-counted chunks with the video URL attached, ready for embeddings and a vector database — the base of a "chat with this channel" bot.

Timestamped quotes and chapter drafts

Keep includeSegments on. Each segment has a start time in seconds, so a script can find the moment a phrase is said and build a link like https://www.youtube.com/watch?v=VIDEO_ID&t=754s. Grouping segments by minute or by topic gives you a first draft of video chapters.

Summaries and content repurposing

Send text to the language model of your choice to produce summaries, show notes, blog drafts or social posts. Because the transcript arrives as structured data, it's easy to schedule: a daily run on a channel URL picks up new uploads and your summariser processes only the new rows.

FAQ

Do I need a YouTube API key?

No. The tool reads the captions YouTube itself serves for public videos. You only need an Apify account.

What happens if a video has no captions?

You get a row with error: "no captions" and no charge. Videos whose uploader turned captions off, and some age-restricted videos, fall into this group.

Can I get transcripts in another language?

Set language to the two-letter code you want, such as de or es. If that track doesn't exist, the fallback order above applies, and availableLanguages shows every language the video actually offers.

Does it work on private or unlisted videos?

Unlisted videos work when you have the URL. Private videos return an error, because their captions aren't public.

Why do long videos take longer?

A two-hour video can have thousands of caption segments. Parsing them takes 10–20 seconds per video, which is normal. Split very large lists into several runs if you want results sooner.

Can an AI assistant use it directly?

Yes. Through the Apify MCP server, an assistant with MCP support can run the tool on a video link and read the transcript itself — for example to answer questions about a talk you haven't watched yet.
