Small first run

Turn website fields into a spreadsheet

Start with one page and one field. Then replace the URL and selector with a product title, price or stock status.

1. Copy the starter input

Use this bounded input for your first run. It is a recipe, not recorded output. Download input JSON

{
  "urls": [
    "https://example.com/"
  ],
  "selectors": [
    {
      "name": "title",
      "selector": "title",
      "type": "text"
    }
  ],
  "firstMatchOnly": true,
  "maxConcurrency": 1,
  "maxPages": 1,
  "proxyMode": "never"
}

2. Open the Actor and review your budget

Open the Actor, switch Input to JSON and paste the input above. Review the Pricing tab and set Maximum cost per run before you start. The link does not start a paid run.

Open Web Scraper — CSS Selector & Data Extractor →

3. Check the result before exporting

Check error is empty and matchCounts.title is greater than zero. The title field is inside fields. A successful run with a null field is not a successful extraction.

Export the successful dataset as JSON, CSV or Excel. Read the full guide for field meanings and the next step.

Know the limits

Reads static HTML only. Use the browser version for fields inserted by JavaScript. This starter does not follow links or use a proxy.

Check exported JSON on your computer

Download the local result checker. It requires Node.js 20 or newer, has no dependencies and makes no network requests. Export a JSON array from Apify and keep the file on your computer.

node check-results.mjs css current.json title

Replace title with your required field names, separated by commas, such as title,price. Every required field must have a value and at least one selector match; zero is a valid value. Exit code 0 means the field checks passed; 2 means review the rows; 1 means the file or command could not be read. An empty dataset needs review.

Use the input in n8n

Download the manual n8n starter. Import it and select an HTTP Header Auth credential in the HTTP Request node: name Authorization, value Bearer followed by your Apify token. Store it in n8n credentials, never in the exported JSON.

The workflow is inactive and extracts data only. It does not schedule, compare results or send alerts. Import and a live run must be checked in your n8n installation. If the synchronous request times out, check Apify before retrying to avoid duplicate work and charges.
