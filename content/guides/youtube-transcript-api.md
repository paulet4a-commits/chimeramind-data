Transcripts are the most useful part of a YouTube video for anything that isn't watching it: summarising a talk, searching a course library, quoting a podcast, or feeding an AI model that answers questions about a channel. YouTube shows them one video at a time behind a menu, and the official Data API does not let third-party apps download caption text without the channel owner's authorisation. This guide shows how to get **the full transcript of many videos at once** — plain text plus timestamped segments — through a simple JSON API, for {{price}}.

## What you get

One row per video: the video and channel identifiers, title, duration, the caption track that was used, every language the video offers, the whole transcript as one `text` string and — unless you turn it off — a `segments` array of `{start, dur, text}` objects. A real row from a recorded run, trimmed:

{{sample}}

| Field | Meaning |
|---|---|
| `videoId`, `url`, `title` | The video |
| `channelName`, `channelId` | Who uploaded it |
| `durationSeconds`, `publishDate` | Length, and the publish date in ISO 8601 UTC (null when YouTube does not report it) |
| `language`, `languageName`, `isAutoGenerated` | Which caption track was extracted, and whether YouTube generated it automatically |
| `availableLanguages` | Every caption language the video offers |
| `text` | The whole transcript as one plain-text string |
| `segments`, `segmentCount` | Timestamped pieces with start time and duration in seconds |
| `transcriptComplete`, `transcriptCoverage` | Whether the captions reach the end of the video, and how much of it they cover |
| `viewCount`, `scrapedAt` | View count at extraction time and the extraction timestamp |
| `error` | Why a video had no transcript, for example `no captions` |

## Which caption track you get

Set a preferred `language` (two-letter code, `en` by default). If the video has captions in that language, you get them. If not, the tool falls back in this order: the first manually created track in any language, then the first auto-generated track (when **Include auto-generated captions** is on, the default), then any track at all. The row always says what you received through `language` and `isAutoGenerated`, so a pipeline can filter out auto-captions or other languages.

## Check that the transcript is complete

YouTube's caption track sometimes ends before the video does, with silent endings, music or auto-captions that stop early. `transcriptCoverage` is the end time of the last caption segment divided by the video's duration (0 to 1), and `transcriptComplete` is `false` when that coverage falls below 90 %. Treat `false` as "captions are partial", not as a failed run. Filter on it before you summarise or index a video.

## Step-by-step

1. Paste videos into **Video URLs**: full `watch?v=` links, Shorts links, `youtu.be` links or bare 11-character IDs, one per line.
2. Or set **Channel URL** (for example `https://www.youtube.com/@channelname`) and **Max videos** to take the channel's latest uploads. A channel URL overrides the video list.
3. Pick your **Language** and decide whether to include auto-generated captions and segments. Turn segments off if you only need the text; the dataset becomes much smaller.
4. Leave **Proxy mode** on `auto`. Requests go out directly and switch to a residential proxy only if YouTube starts rate-limiting.
5. Click **Start** and export as JSON, CSV or Excel, or read the rows through the API.

## Use it in n8n or Make

Call the API from a workflow tool with the **HTTP Request** node in **n8n**: method `POST`, URL `https://api.apify.com/v2/acts/webdatatools~youtube-transcript-scraper/run-sync-get-dataset-items`, a header `Authorization` with the value `Bearer YOUR_APIFY_TOKEN`, and a JSON body. The response is one item per video. In **Make**, use **HTTP > Make a request** with the same method, URL and header, body type Raw with JSON content, and **Parse response** on, then iterate over the array.

Synchronous calls wait for the run to finish, so use them for a handful of videos. For a whole channel, start the run asynchronously and read the dataset when it completes.

Body example:

```json
{
    "videoUrls": ["https://www.youtube.com/watch?v=dQw4w9WgXcQ", "jNQXAC9IVRw"],
    "language": "en",
    "includeAutoGenerated": true,
    "includeSegments": false
}
```

## Recipes

### Turn a channel into a searchable knowledge base
Run the Actor with a **Channel URL** and a generous **Max videos**, then pass the run's dataset to [RAG Text Chunker](/tools/rag-text-chunker/) with the transcript run's dataset ID and `text` as the text field. You get token-counted chunks with the video URL attached, ready for embeddings and a vector database.

### Timestamped quotes and chapter drafts
Keep segments on. Each segment has a `start` time in seconds, so a script can find the moment a phrase is said and link to it with `https://www.youtube.com/watch?v=VIDEO_ID&t=754s`. Grouping segments by minute or by topic gives you a first draft of chapters.

### Summaries and content repurposing
Send `text` to the language model of your choice for summaries, show notes or social posts. Schedule a daily run on a channel URL and your summariser only processes the rows that are new.

## Limits

- Captions only. Views, likes and comments are not part of the output; use [YouTube Video Details](/tools/youtube-video-details/) for video metadata.
- Public videos only. Private videos return an error, and live chat messages are not included.
- Languages are limited to the caption tracks YouTube offers. `availableLanguages` lists what a given video has.

## FAQ

### Do I need a YouTube API key?
No. The tool reads the captions YouTube serves for public videos. You only need an Apify account.

### What happens if a video has no captions?
You get a row with `error: "no captions"` and no charge. Videos whose uploader turned captions off, and some age-restricted videos, fall into this group.

### Can I get transcripts in another language?
Set `language` to the code you want, such as `de` or `es`. If that track does not exist, the fallback order above applies, and `availableLanguages` shows every language the video offers.

### Does it work on private or unlisted videos?
Unlisted videos work when you have the URL. Private videos return an error, because their captions are not public.

### Why does a long video take longer?
A two-hour video can have thousands of caption segments, and parsing them takes 10 to 20 seconds per video. That is normal. Split very large lists into several runs if you want results sooner.

### Can an AI assistant use it directly?
Yes. Through the Apify MCP server, an assistant that supports MCP can run the Actor on a video link and read the transcript itself, for example to answer questions about a talk you have not watched.
