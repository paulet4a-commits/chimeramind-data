YouTube channel & video research

List the uploads of a channel, pull views and likes per video, then read the comments and full transcripts for content, sponsor and audience research.

  1. YouTube Channel Scraper (videos, shorts, live)

    Export a public YouTube channel's videos, Shorts or livestreams: titles, views, duration, publish time and thumbnails. Use handles, channel IDs or URLs; limit results for a small first run, then schedule repeat exports. No YouTube Data API key required.

  2. YouTube Video Details Scraper (views, likes, description, tags)

    YouTube Video Details Scraper returns views, likes, description, tags, category, channel and comment count for any YouTube video URL or ID — no YouTube Data API key or quota needed.

  3. YouTube Comments Scraper — Comments & Replies

    Comments Scraper extracts comments, replies, likes and author details from any YouTube video URL or ID — no YouTube Data API key or quota needed.

  4. YouTube Transcript Scraper

    1 result = the full transcript of 1 video, $0.004/video (FREE). YouTube captions with timestamped segments, publish date, view count and a completeness check. Multiple languages and auto-generated captions.

These are suggested research steps. Review each input schema and map the output fields between steps; each tool is billed separately at its listed price.
