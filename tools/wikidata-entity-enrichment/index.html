Wikidata Entity & Company Enrichment (facts, IDs, links)

Wikidata Entity & Company Enrichment resolves a QID, company name, or Wikipedia URL to its Wikidata item and returns facts (country, HQ, founders, CEO, employees, revenue), identifiers (ISIN, Crunchbase, LinkedIn) and social/media links — one row per entity.

Call from code

Use the existing catalog input below as a starting point. Review the tool's input form on Apify before running it.

import json
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run = client.actor("webdatatools/wikidata-entity-enrichment").call(run_input=json.loads("{\n    \"entities\": [\n        \"Q95\",\n        \"Apify\",\n        \"https://en.wikipedia.org/wiki/Stripe,_Inc.\"\n    ],\n    \"language\": \"en\",\n    \"entityType\": \"any\"\n}"))

for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)
import { ApifyClient } from 'apify-client';

const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);
