Call from code

Use the existing catalog input below as a starting point. Review the tool's input form on Apify before running it.

import json
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run = client.actor("webdatatools/bulk-image-downloader").call(run_input=json.loads("{\n    \"imageUrls\": [\n        \"https://commons.wikimedia.org/wiki/Special:FilePath/Cat03.jpg\"\n    ],\n    \"datasetId\": \"\",\n    \"urlField\": \"url\",\n    \"maxImages\": 50,\n    \"maxFileSizeMb\": 20,\n    \"timeoutSecs\": 30,\n    \"createZip\": false\n}"))

for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

Use with an AI agent or CLI

Connect a remote-capable MCP client to this Actor through Apify. Use the official MCP configurator for your client, then sign in with your own Apify account. Calls are charged to your account at the Actor's current rates.

https://mcp.apify.com?tools=webdatatools/bulk-image-downloader

Ask your agent to inspect webdatatools/bulk-image-downloader, show you the input and estimated cost, then run a small sample. With call-actor, set callOptions.maxTotalChargeUsd to your budget; this is a run option, not an input field. Read the returned dataset with get-dataset-items. Review errors and output before scaling.

For the Apify CLI, authenticate locally and save the catalog input JSON as input.json. Review its URLs and limits first. This command starts a paid cloud run:

apify actors info webdatatools/bulk-image-downloader --input
apify actors call webdatatools/bulk-image-downloader --input-file input.json

The CLI call above does not set a spending ceiling. For an explicit per-run cost cap, use the MCP run option described above or set Maximum cost per run in Apify Console.

Never paste credentials into a prompt or input file. A timeout does not prove the cloud run stopped: inspect it before retrying. Connection and authentication reference.
