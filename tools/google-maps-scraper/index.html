Call from code

Use the existing catalog input below as a starting point. Review the tool's input form on Apify before running it.

import json
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run = client.actor("webdatatools/google-maps-scraper").call(run_input=json.loads("{\n    \"searchQueries\": \"dentist\",\n    \"location\": \"Austin, TX\",\n    \"maxPlacesPerSearch\": 20\n}"))

for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)
import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: process.env.APIFY_TOKEN });
const run = await client.actor('webdatatools/google-maps-scraper').call({
    "searchQueries": "dentist",
    "location": "Austin, TX",
    "maxPlacesPerSearch": 20
});
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

Use with an AI agent or CLI

Connect a remote-capable MCP client to this Actor through Apify. Use the official MCP configurator for your client, then sign in with your own Apify account. Calls are charged to your account at the Actor's current rates.

https://mcp.apify.com?tools=webdatatools/google-maps-scraper

Ask your agent to inspect webdatatools/google-maps-scraper, show you the input and estimated cost, then run a small sample. With call-actor, set callOptions.maxTotalChargeUsd to your budget; this is a run option, not an input field. Read the returned dataset with get-dataset-items. Review errors and output before scaling.

For the Apify CLI, authenticate locally and save the catalog input JSON as input.json. Review its URLs and limits first. This command starts a paid cloud run:

apify actors info webdatatools/google-maps-scraper --input
apify actors call webdatatools/google-maps-scraper --input-file input.json

The CLI call above does not set a spending ceiling. For an explicit per-run cost cap, use the MCP run option described above or set Maximum cost per run in Apify Console.

Never paste credentials into a prompt or input file. A timeout does not prove the cloud run stopped: inspect it before retrying. Connection and authentication reference.
