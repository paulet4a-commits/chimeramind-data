Call from code

Use the existing catalog input below as a starting point. Review the tool's input form on Apify before running it.

import json
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run = client.actor("webdatatools/website-to-markdown").call(run_input=json.loads("{\n    \"startUrls\": [\n        {\n            \"url\": \"https://docs.apify.com/platform\"\n        },\n        {\n            \"url\": \"https://crawlee.dev/docs\"\n        }\n    ],\n    \"maxPages\": 50,\n    \"maxDepth\": 3\n}"))

for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

Use with an AI agent or CLI

Connect a remote-capable MCP client to this Actor through Apify. Use the official MCP configurator for your client, then sign in with your own Apify account. Calls are charged to your account at the Actor's current rates.

https://mcp.apify.com?tools=webdatatools/website-to-markdown

Ask your agent to inspect webdatatools/website-to-markdown, show you the input and estimated cost, then run a small sample. With call-actor, set callOptions.maxTotalChargeUsd to your budget; this is a run option, not an input field. Read the returned dataset with get-dataset-items. Review errors and output before scaling.

For the Apify CLI, authenticate locally and save the catalog input JSON as input.json. Review its URLs and limits first. This command starts a paid cloud run:

apify actors info webdatatools/website-to-markdown --input
apify actors call webdatatools/website-to-markdown --input-file input.json

The CLI call above does not set a spending ceiling. For an explicit per-run cost cap, use the MCP run option described above or set Maximum cost per run in Apify Console.

Never paste credentials into a prompt or input file. A timeout does not prove the cloud run stopped: inspect it before retrying. Connection and authentication reference.
